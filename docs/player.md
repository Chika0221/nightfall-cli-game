# NIGHTFALL：ノアの亡命 — 開始案内

ファイルに残された記録から状況を調べる、Unix CLIの調査ゲームです。実際のBashで探索・検索・比較・編集を行います。Windows 11とWSL 2を使い、DockerやPythonの個別インストールは不要です。

## 初回の準備

1. 運営から受け取った配布フォルダを展開してください。
2. `初回セットアップ.cmd` をダブルクリックします。
3. WSLが未導入の場合は運営またはPC管理者に導入を依頼し、準備後にセットアップを再実行します。
4. `ゲーム開始.cmd` をダブルクリックします。

学校のPCで実行を制限されている場合は運営に相談してください。

## 調査の始め方

`mission` で接続先を確認し、`cat ~/inbox/request.txt` で届いた依頼を読んでください。最初から公開されている資料は自由に調べられます。記録中に見つけた参照番号を照会すると、新しい資料が届くことがあります。

| 操作 | 内容 |
|---|---|
| `mission` | 接続先と受信箱を表示 |
| `mission fetch 参照番号` | 記録を照会・取得 |
| `mission help` | コマンド操作と復旧の手引き |
| `mission hint` | 調査状況に応じたヒント。3段階、減点なし |
| `mission hints` | 表示済みヒントを再表示 |
| `mission status` | 取得記録・経過時間・練習用保存地点番号 |
| `vault unlock archive` / `vault unlock core` | 保管庫を認証 |
| `mission check` | 協力者報告を送信 |
| `mission submit` | 移送資料を送信 |
| `mission reset` | 最後の保存地点に復元。範囲の表示と確認あり |

送信物の形式はゲーム内の資料に記載されています。操作は端末内で完結し、外部への送信はありません。物語の解釈を回答する試験はありません。

`less` と `man` は `q` で終了。`nano` は `Ctrl+O` → `Enter` で保存、`Ctrl+X` で終了します。通常 `Ctrl+C` でコマンドを中断できます。

パスワード入力中は文字も `*` も表示されません。そのまま入力し、`Enter` を押してください。

## 終了・再開・復旧

`exit` で終了します。次回起動時には保存済みの進捗とファイルを引き継ぎます。プレイ中のネット接続は不要。120分を超えても続けられ、実時間による救出失敗はありません。

記録取得・認証・回収・報告送信が成功すると保存地点が更新されます。`mission reset` はホームと公開領域を最後の保存地点へ戻し、それ以後のファイル編集を取り消します。取得した資料や認証状態は維持します。ホーム全体の削除や起動不能の場合は運営に復旧を依頼してください。

`mission replay N` で到達済みの保存地点の練習を予約できます。`exit` 後に独立した練習環境が開き、練習を終了すると本編に戻ります。本編の進捗は変わりません。練習は標準の調査順で再現されるため、本編で取得した資料の順序とは異なる場合があります。
