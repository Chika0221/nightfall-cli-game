# NIGHTFALL 開始案内

NIGHTFALLは、ファイルの探索や検索をしながら証拠を集めるゲームです。Windows 11とWSL 2を使います。DockerやPythonを自分でインストールする必要はありません。

## 初回の準備

1. 運営から受け取った配布フォルダを展開してください。圧縮フォルダの中から直接実行しないでください。
2. `初回セットアップ.cmd`をダブルクリックしてください。
3. WSLが未導入の場合は、運営またはPCの管理者に導入を依頼してください。導入時にはネット接続やWindowsの再起動が必要になる場合があります。準備後、セットアップをもう一度実行します。
4. セットアップが完了したら、`ゲーム開始.cmd`をダブルクリックしてください。

学校のPCで実行を制限されている場合は、運営に相談してください。端末の制限設定を自分で変更する必要はありません。

## 遊び方

表示された依頼を読み、実際のコマンドでファイルを調べます。まずは `mission` と入力してください。

| 操作 | 内容 |
|---|---|
| `mission` | 現在の依頼と操作の手引き |
| `mission check` | 回答を入力、または成果物を確認 |
| `mission hint` | 次のヒントを表示（全3段階、減点なし） |
| `mission hints` | 見たヒントを再表示 |
| `mission help` | 操作説明と復旧案内 |
| `mission status` | 進捗・時間・ヒント数 |
| `mission reset` | 現在の課題を復元（対象を確認後、`yes`で実行） |

`less`と`man`は `q` で終了します。`nano`は `Ctrl+O` → `Enter` で保存、`Ctrl+X`で終了します。実行中のコマンドは通常 `Ctrl+C` で中断できます。

パスワード入力中は、文字も `*` も表示されません。そのまま入力して `Enter` を押してください。

## 終了・再開・練習

`exit`で終了します。次回は `ゲーム開始.cmd` を開くと続きから再開できます。ウィンドウを閉じても、保存済みの進捗やファイルは残ります。プレイ中のネット接続は不要です。120分を超えても続けられます。

`mission replay N`で到達済みのステージを練習できます。予約後に `exit` すると、新しい練習環境が開きます。練習を `exit` で終了すると本編に戻ります。本編の証拠・進捗は変わりません。練習の予約は本編から行ってください。

誤って編集・削除したら `mission reset` を使います。ホーム全体を消した場合や起動できない場合は、運営に復旧を依頼してください。
